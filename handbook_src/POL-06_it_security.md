# POL-06 IT Acceptable Use and Security Policy

## 1. Accounts and passwords
1.1 Passwords must be at least 14 characters long.
1.2 Multi factor authentication is mandatory for email, VPN and all cloud systems.
1.3 Passwords must not be shared with anyone, including IT staff.

## 2. Devices
2.1 Company laptops must have disk encryption and automatic updates enabled.
2.2 Personal devices (BYOD) may access company email only after enrolment in the mobile device management system.
2.3 USB mass storage devices are blocked by default. Exceptions need IT Security approval.
2.4 A lost or stolen device must be reported to IT Security at security@meridianworks.example within 2 hours of discovery.

## 3. Data handling
3.1 Company data must be stored only in approved company systems.
3.2 Use of personal cloud storage or personal email to store or send company data is prohibited.
3.3 Generative AI tools may be used only if approved by IT Security. Confidential and customer data must never be entered into unapproved tools.

## 4. Software
4.1 Only software from the approved list may be installed on company laptops.
4.2 Requests for new software go to the IT service desk on extension 2200.

## 5. Incidents
5.1 Suspected phishing must be reported using the report button in the email client.
5.2 Any security incident must be reported immediately to security@meridianworks.example.
